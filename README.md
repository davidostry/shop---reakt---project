#  Mini Shop

Mini Shop is a small online shop built with **React, TypeScript, and Vite**.

The application displays products from the Fake Store API and allows users to search for products, view product details, and manage a list of favorite products.

## Technologies

* React
* TypeScript
* Vite
* React Router
* Zustand
* CSS


* Add products to favorites.
* Remove products from favorites.
* Prevent duplicate products from being added.
* Favorites are managed globally using Zustand.
* Displays an empty-state message when there are no favorites.

Installation

git Clone
npm install
npm run dev
